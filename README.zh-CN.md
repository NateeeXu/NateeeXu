## 🆕 最新项目：Saviu

灾害发生时，保险公司要先弄清楚该优先帮谁。Saviu 把受灾区域地图、短信报平安和保单数据融合成一张实时优先级地图，连一直没有回音的人也会标出来。现场上报的信息会随时更新这张图。

🚨 **[Saviu](https://github.com/NateeeXu/UTD_ZERODAY)**：HackUTD 2026 上两人组队完成，参加 State Farm 和 Spacetime 两个赛道。地理和人口数据来自真实公开数据，住户、风暴和短信回复都是模拟的。

## ⭐ 代表项目

三个关于学生租房的产品，加一个追踪 AI 构建者动态的网站。

☁️ **[CloudSublet](https://cloudsublet.com)**（80 名内测用户）- 面向留学生的转租平台，覆盖 Northwestern、UChicago、UC Berkeley 和 Yale。由我创立，微信小程序也是我一个人做的。两轮内测覆盖了转租方和求租方的 122 个测试场景。

🔑 **[Rentlet](https://rentlet-nu.web.app/)**（课程项目）- Northwestern 学生之间的转租和转让租约平台，只允许 Northwestern 账号登录，支持站内聊天。基于 Firebase。[源码](https://github.com/NateeeXu/rentlet)

🏡 **[安窝 Anwo](https://github.com/NateeeXu/anwo)**（原型）- 面向留学生的校园生活平台：转租、实时聊天、身份验证、地图、校车、二手交易，还能找搭子拼车、一起去 Costco。目前是约 66 所高校的演示数据，支付和短信为模拟实现。

🌟 **[Shining Builders](https://nateeexu.github.io/follow-builders-feishu/)**（每日更新）- 看 AI 构建者在说什么，以及哪些 AI 工具在 GitHub 上涨星最快。在 Zara Zhang 的 [follow-builders](https://github.com/zarazhangrui/follow-builders) 基础上扩展，不依赖付费 API。[源码](https://github.com/NateeeXu/follow-builders-feishu)
